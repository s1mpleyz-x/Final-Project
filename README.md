# Memory Card Game
> A simple memory card game built with HTML, CSS, and JavaScript. The game challenges players to match pairs of cards by flipping them over and remembering their positions.

## Live Demo
[Try it here!](https://s1mpleyz-x.github.io/Final-Project/)

## Technologies Used
* `HTML`
* `CSS`
* `JavaScript`

## Setup and Installation
1. Clone the repository
```bash
   git clone https://github.com/s1mpleyz-x/Final-Project.git
```
2. Navigate into the project folder
```bash
   cd Final-Project
```
3. Open `index.html` in your browser
   - Double-click the file, or
   - Use a tool like VS Code's Live Server extension for auto-reloading during development

> [!WARNING]
> The path for the images in `index.html` are relative to the project root. If you move `pictures/` or restructure folders, update the `img` paths in `index.html` accordingly.

## How it works
 Once a card is flipped, the next card flipped must match the first card to make a pair. The game continues until all pairs are matched. There is a panel at the top that shows the number of moves made and a restart button to reset the game.
